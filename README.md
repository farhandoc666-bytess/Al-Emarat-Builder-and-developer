# Al Emarat Builder and Developer — Website

Static responsive company website for **Al Emarat Builder and Developer**, serving Islamabad and Rawalpindi.

**Contact:** +92 348 8007387  
**Office:** Diamond Mall & Residency, Tower 2

## What's included
- Homepage, property service categories, construction services, location coverage, gallery and contact section
- Mobile-friendly navigation and interactive enquiry controls
- WhatsApp enquiry forms
- Original website images, logos and video assets

## Preview locally
Open `index.html` in your browser, or run `START_WEBSITE.bat` on Windows.

## Publish with GitHub Pages
1. Create a repository on GitHub, for example `al-emarat-website`.
2. Upload **the extracted files**, keeping `index.html`, `styles.css`, `script.js`, and `assets/` in the repository root.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** in your repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Set branch **main** and folder **/(root)**, then select **Save**.
7. Wait for the deployment and open the Pages link shown under Settings → Pages.

Do not upload only this ZIP file into the repository: GitHub Pages needs `index.html` and the assets as separate files.

## Important
This is a **static frontend**. The property cards are enquiries/categories rather than live verified inventory. Forms open prefilled WhatsApp messages; they do not store submissions in a database. A future property management dashboard requires WordPress or another backend.

Verify you hold rights to publish all imagery and videos (some source material may have third-party watermarks) before making a public repository or publishing the site. GitHub Pages sites are publicly accessible, even if the repository is private.
